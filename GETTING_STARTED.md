# Getting Started with CompanyMail HR

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Pages

- Dashboard: `/dashboard`
- Directory: `/directory`
- Emails: `/emails`
- Documents: `/documents/generate`
- Templates: `/templates`
- Settings: `/settings`

## Deployment

Click the Vercel button in README.md to deploy live!
