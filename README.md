# CompanyMail HR - AI-Powered HR Management SaaS

A modern HR management platform built with Next.js 14, React 19, TypeScript, and Tailwind CSS.

## Features

- 📊 Dashboard with metrics and activity
- 👥 Employee Directory with search
- 📧 Business Email Inbox
- 📄 AI Letter Generator
- 📋 Template Management
- ⚙️ Company Settings

## Tech Stack

- Next.js 14 + React 19 + TypeScript
- Tailwind CSS v4
- PostgreSQL + Prisma ORM
- NextAuth.js (authentication)
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- `/dashboard` - Main dashboard
- `/directory` - Employee directory
- `/emails` - Email inbox
- `/documents/generate` - Letter generator
- `/templates` - Template management
- `/settings` - Company settings
